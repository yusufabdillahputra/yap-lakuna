# Rencana v0.7.0: QRIS statis + split payment

Spec: [F1-05 Pembayaran](../specs/2026-11-03-f1-05-pembayaran-design.md)
(Lingkup v0.7.0) dan [F1-18 Pengaturan](../specs/2026-11-03-f1-18-pengaturan-design.md)
(Lingkup v0.7.0).

**Tujuan:** kasir bisa menerima QRIS statis dengan konfirmasi manual dan
membagi pembayaran ke beberapa metode; pemilik mengunggah stiker QRIS di
Pengaturan.

**Arsitektur:** aturan pelunasan dan validasi gambar di `lakuna_domain`
(Dart murni); model `MediaFile` + migrasi `qris` di server; `lakuna_data`
menyimpan pengaturan QRIS di `settings` dan file di folder `media`;
`checkoutSale` menerima daftar pembayaran; aplikasi menambah
`PaymentSettingsRepository`, bagian pengaturan QRIS, panel QRIS dan panel
split di tahap bayar.
