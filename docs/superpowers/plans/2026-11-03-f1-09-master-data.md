# Rencana F1-09 · Master data

Spec: [`2026-11-03-f1-09-master-data-design.md`](../specs/2026-11-03-f1-09-master-data-design.md).

Ringkas: kolom baru di `categories` (migrasi `master`); aturan nama/induk/
warna/urutan di `lakuna_domain`; CRUD kategori & satuan di `lakuna_data`
(`master_data.dart`); repositori + view model + layar `/master`; kasir dan
form produk mengikuti saklar kategori.
