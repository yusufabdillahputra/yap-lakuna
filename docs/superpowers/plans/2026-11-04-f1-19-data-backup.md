## Catatan review

Temuan review (diperbaiki sebelum rilis): pemasangan pulihkan dibuat tahan
crash (`restore/applying`), data lama dikembalikan bila database backup
gagal dibuka (`undoRestore`), zip ditutup setelah dibaca, database
diekstrak dan di-hash dari berkas (tidak ditampung di memori), salinan
sementara dibersihkan, nama gambar dengan `\` / `:` ditolak, versi skema
kosong = berkas tidak sah, *backup terakhir* diisi waktu backup setelah
pulihkan, berkas desktop di menit yang sama tidak saling menimpa.
