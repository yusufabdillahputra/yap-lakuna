# Rencana F1-11 · Riwayat transaksi, void & retur (v0.15.0)

Spec: `docs/superpowers/specs/2026-11-03-f1-11-riwayat-void-retur-design.md`.

**Arsitektur.** Aturan nilai retur dan transisi status ada di
`lakuna_domain`. Kueri riwayat, retur, void, dan persetujuan ada di
`lakuna_data`. Aplikasi memakai `HistoryRepository` dengan versi lokal dan
palsu, `HistoryViewModel`, layar `/riwayat` dan `/riwayat/:id`, dialog
retur, dialog void + persetujuan PIN, cetak ulang lewat layanan struk yang
sudah ada, dan ekspor Excel.

## 1 · Domain

- [ ] `sale_return.dart`:
  - [ ] `ReturnLimits` (catatan maks 200, alasan).
  - [ ] `returnNumber(outlet, device, local, counter)` → `RT-…`.
  - [ ] `lineShares(total, lineTotals)` memakai `allocateByWeight`.
  - [ ] `returnAmount(share, qty, returnedBefore, returningNow)` dengan
    pembulatan ke bawah; retur terakhir mengambil sisa.
  - [ ] `saleStatusAfterReturn(soldQty, returnedQty)`.
  - [ ] Tes di `test/sale_return_test.dart`.

## 2 · Model server & migrasi

- [ ] Enum `SaleReturnReason`, `RefundMethod`; `SaleStatus` +
  `partiallyReturned`, `returned`.
- [ ] Model `sale_returns`, `sale_return_items`.
- [ ] `serverpod generate`, `create-migration --tag riwayat`.

## 3 · Data

- [ ] `history.dart`:
  - [ ] `HistoryFilter` (rentang tanggal lokal, staf, metode, status).
  - [ ] `listSales` → baris ringkas (nomor, waktu, kasir, metode, total,
    diretur, status), urut terbaru.
  - [ ] `historySummary` (jumlah dan total bersih).
  - [ ] `loadSaleDetail` (sale, item, pembayaran, modifier, retur, sisa per
    baris, bagian per baris, `canVoid` beserta alasannya).
- [ ] `sale_return.dart`:
  - [ ] `returnSale` dalam satu transaksi: validasi jumlah, nilai, nomor
    `RT-`, item, restok `saleReturn`, status nota.
  - [ ] Tunai wajib sesi buka.
- [ ] `voidSale`:
  - [ ] Validasi hari ini, sesi buka perangkat, tanpa retur.
  - [ ] Pembalikan stok dan status `voided`.
  - [ ] `voided_by` = penyetuju.
- [ ] `verifyApprover(staffId, pin, permission)` dengan `PinGuard` yang
  sama dengan login, dan pemeriksaan role.
- [ ] Rekap sesi: `sessionSalesSummary` mencakup nota yang diretur, dan
  `cashRefunds` dari retur tunai sesi. Layar tutup sesi memakainya.
- [ ] Tes di `test/history_test.dart`.
