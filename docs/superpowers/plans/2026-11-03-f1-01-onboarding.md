# Rencana F1-01 · Onboarding & setup toko

Spec: [`../specs/2026-11-03-f1-01-onboarding-design.md`](../specs/2026-11-03-f1-01-onboarding-design.md).
Target rilis v0.2.0. Setiap tugas: tes gagal dulu, lalu kode, lalu tes lulus.

## Tugas

1. [ ] **Domain: `SetupInput` + validasi** (`packages/lakuna_domain/lib/src/setup.dart`)
   - Tes: kode 2–6 huruf/angka (huruf kecil dinaikkan, spasi dipangkas), nama
     1–60, email, kata sandi ≥ 8, PIN 6 angka + konfirmasi, zona waktu.
   - `SetupField` enum + `SetupError` enum; `validate()` → `Map<SetupField, SetupError>`.
   - `setupTimezones` (WIB/WITA/WIT).
2. [ ] **Domain: `CredentialHasher`** (`credentials.dart`, paket `hashlib`)
   - Tes: hash → verify benar/salah, dua hash berbeda (salt), awalan
     `$argon2id$v=19$m=19456,t=2,p=1$`. Parameter bisa diperkecil untuk tes.
3. [ ] **Model: kolom `staff_members.password_hash`**
   - `serverpod generate`, `serverpod create-migration --tag onboarding`,
     salin migrasi klien; tes server tetap lulus.
4. [ ] **Data: `StoreSetup` / `StoreRepository`** (`packages/lakuna_data/lib/src/store_setup.dart`)
   - Tes: 6 baris + 6 outbox dalam satu transaksi, aktor = pemilik, perangkat
     memakai `store.deviceId`, setup kedua → `SetupAlreadyDone`, galat
     membatalkan semua, `loadContext()` null sebelum setup dan terisi setelahnya.
5. [ ] **Aplikasi: repositori + view model**
   - `StoreRepository` abstrak (`loadContext`, `setup`) + versi lokal + palsu.
   - `OnboardingViewModel`: langkah, field, galat per langkah, pratinjau nota,
     `Command0 finish` (hash di isolate lewat repositori lokal).
   - Tes view model.
6. [ ] **Aplikasi: layar 1.1** (`lib/ui/onboarding/`)
   - Tablet/desktop dua kolom dengan panel Sky; mobile dengan progress bar.
   - Kunci i18n id + en, `flutter gen-l10n`.
   - Tes widget alur lengkap (tablet dan mobile).
7. [ ] **Router**: redirect ke `/setup` bila `StoreContext` null; `/setup` ditolak
   setelah setup. Beranda menampilkan usaha · cabang · perangkat. Tes router.
8. [ ] **Verifikasi**: format, analyze, semua tes, uji manual Xvfb dengan
   tangkapan layar (tablet/mobile, terang/gelap).
9. [ ] **Dokumen & rilis**: CHANGELOG 0.2.0, versi `0.2.0+3`, Status & gap spec,
   indeks spec, review subagent, PR, merge, cek rilis.
