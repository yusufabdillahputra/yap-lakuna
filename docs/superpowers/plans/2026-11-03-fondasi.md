# Rencana · Fondasi Lakuna (v0.1.0)

Spec: [F0 · Fondasi & arsitektur](../specs/2026-11-03-f0-fondasi-arsitektur-design.md).
Setiap langkah TDD: tulis tes, lihat gagal, tulis kode, lihat lulus.

## 1. Monorepo

- [x] Proyek dibuat dengan `serverpod create` 4.1 (`lakuna_server`,
      `lakuna_client`, `lakuna_flutter`) dalam pub workspace.
- [x] Paket `packages/lakuna_domain` dan `packages/lakuna_data` masuk
      workspace.
- [x] Perangkat AI Serverpod: `AGENTS.md`, `.mcp.json` (MCP serverpod +
      dart), skill di `.claude/skills/`.
- [x] Template contoh (greeting, google_fonts, layar login template) dihapus.

## 2. `lakuna_domain` (Dart murni)

- [x] `Money` (rupiah bulat), `BasisPoints`, pembulatan setengah menjauhi
      nol lewat BigInt; format `Rp 12.500` / `IDR 12,500`.
- [x] `Qty` mili-satuan dan konversi satuan dasar.
- [x] `newId()` UUIDv7.
- [x] `Permission` (21 izin) dan `DefaultRole` (5 role) sama dengan Storeku.
- [x] `receiptNumber`, `documentNumber`, `DailyCounter`.
- [x] `Hlc` (parse, tick, receive, urutan).

## 3. Model Serverpod dan migrasi

- [x] Model organisasi `database: all`: tenants, outlets, stock_locations,
      devices, settings, staff_members, outlet_members dengan kolom sync
      standar dan nama kolom `snake_case` (`column=`).
- [x] Model lokal `database: client`: sync_outbox,
      sync_state, local_preferences.
- [x] Migrasi `fondasi` untuk server dan klien.
- [x] Tes integrasi server (`withServerpod`) untuk default kolom dan kode
      outlet unik (dijalankan di CI; container lokal tidak bisa menjalankan
      PostgreSQL tertanam sebagai root).

## 4. `lakuna_data`

- [x] `LakunaStore.open` membuat/migrasi SQLite dan ID perangkat sekali.
- [x] Semua tabel `STRICT`.
- [x] `SyncTx.insert/update` menulis outbox di transaksi yang sama;
      rollback membatalkan keduanya.
- [x] HLC naik setiap tulis dan tetap monoton walau jam mundur.
- [x] `LocalPreferences` get/set.

## 5. Aplikasi Flutter

- [x] Tema Forui `conhcc` hasil CLI, varian sentuh/desktop, font dibundel.
- [x] Lokalisasi ARB id (bawaan) + en, tes kesamaan kunci.
- [x] `Result`, `Command0/Command1`.
- [x] `AppSettingsRepository` + implementasi lokal + versi palsu; view model
      pengaturan dengan simpan optimistis dan batal bila gagal.
- [x] Shell responsif: navigasi bawah (mobile), sidebar (tablet/desktop),
      lencana offline.
- [x] Layar beranda (versi, ID perangkat, lokasi data), pengaturan (tema,
      bahasa), halaman "segera hadir" untuk modul lain.
- [x] ID aplikasi `id.lakuna.app` dan nama "Lakuna" di semua platform.
- [x] Tes aset offline (tanpa gambar jaringan / google_fonts / http).
- [x] Perbaikan: judul bilah atas meluap di layar 400 px (ditemukan tes
      mobile) → lencana ringkas + elipsis.
