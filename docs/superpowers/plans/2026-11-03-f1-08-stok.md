# Rencana v0.9.0: Stok

Spec: [F1-08 Stok](../specs/2026-11-03-f1-08-stok-design.md).

**Tujuan:** layar Stok (1.18) dengan daftar stok per lokasi, penyesuaian
multi-produk bernomor, kartu stok bersaldo berjalan, stok minimum, dan
lokasi stok.

**Arsitektur:** model `StockAdjustment` + `StockAdjustmentItem` (Serverpod,
`database: all`, migrasi `stock`); aturan selisih/nilai di `lakuna_domain`;
query dan tulis di `lakuna_data/stock.dart` lewat `recordStockMovement`;
aplikasi menambah `StockRepository` (lokal + palsu), `StockViewModel`,
`StockAdjustmentViewModel`, dan `StockScreen` dengan lima tab.
