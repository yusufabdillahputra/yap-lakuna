# Versi hosting

Versi hosting akan menyinkronkan data semua cabang dan perangkat ke server toko Anda sendiri, sehingga pemilik bisa melihat dashboard semua cabang dari web.

## Status saat ini

Versi hosting masih dikembangkan (Fase 2). Di **Pengaturan › Data & backup**, bagian *Aktifkan versi hosting* sudah tampil tetapi belum bisa dipakai.

## Yang direncanakan

- Sinkronisasi semua data ke database server dan gambar ke penyimpanan objek.
- Server di VPS milik toko sendiri.
- Versi web dengan dashboard semua cabang.
- Transfer stok antarcabang.

> [!note] Sambil menunggu, lakukan [backup](backup-restore) rutin. Data dari versi gratis akan bisa diunggah saat versi hosting tersedia.
