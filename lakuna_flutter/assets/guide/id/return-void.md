# Retur & void

Retur mengembalikan sebagian atau semua barang dari nota yang sudah dibayar. Void membatalkan seluruh nota hari ini. Keduanya tidak menghapus data lama, melainkan mencatat entri baru.

## Retur barang

1. Buka **Riwayat**, lalu pilih nota (pakai filter tanggal, kasir, metode, atau status).

> [!note] Nota lama? Ketik nomor nota, nama atau HP pelanggan, atau no. approval kartu / referensi transfer di kolom **Cari**. Pencarian menjangkau semua tanggal (paling banyak 100 nota terbaru); filter kasir, metode, dan status tetap berlaku. Ketuk pill tanggal untuk kembali ke daftar per tanggal.
2. Tekan **Retur barang**. Isi jumlah retur per item, atau **Retur semua**.
3. Pilih **Alasan**. Untuk *Lainnya*, catatan wajib diisi.
4. Pilih **Uang kembali**: *Tunai dari laci* (butuh sesi kasir terbuka), *Transfer*, atau *Potong piutang* untuk nota kredit.
5. Biarkan **Kembalikan barang ke stok** menyala bila barang masih layak jual.
6. Tekan **Proses retur**.

## Void transaksi

1. Pilih nota di **Riwayat**, lalu tekan **Void transaksi**.
2. Isi **Alasan void**.
3. Bila Anda tidak punya izin *Void nota*, staf yang berizin memasukkan PIN di jendela *Persetujuan manajer*.

> [!warning] Void hanya untuk nota hari ini di sesi kasir yang masih buka di perangkat ini, dan tidak untuk nota yang sudah diretur. Untuk nota lain, pakai retur.

Stok dikembalikan dan nota void tidak dihitung di rekap sesi. Daftar riwayat bisa diunduh dengan **Ekspor Excel**.
