# Hosted version

The hosted version will sync the data of every branch and device to your store's own server, so the owner can see a dashboard of all branches on the web.

## Current status

The hosted version is still in development (Phase 2). In **Settings › Data & backup**, the *Activate hosted version* section is shown but cannot be used yet.

## What is planned

- Syncing all data to a server database and images to object storage.
- A server on the store's own VPS.
- A web version with a dashboard for all branches.
- Stock transfers between branches.

> [!note] Meanwhile, make regular [backups](backup-restore). Data from the free version can be uploaded once the hosted version is available.
